# 프린터 조립 공정 이미지 이상탐지 및 PASS/FAIL 판정

**2026학년도 2학기 「딥러닝의 기초 및 응용」 프로젝트 · 7조**

핸디형 카메라로 촬영한 조립 공정 이미지에서 부품 누락과 문자 오류 등을 검사한 팀 프로젝트다. 불량(NG) 표본이 12장에 불과해 정상 이미지 기반 이상탐지를 비교하고, 검사 목적에 따라 부품 존재 검사와 문자 검사를 분리했다.

**개인 기여:** 모델 개선 전 이미지 품질 확인과 최종 분석 결과 정리·해석 보조. 이 저장소의 모델·통합 코드 전체를 개인이 구현한 것으로 표시하지 않는다.

이 저장소는 [팀 원본 저장소](https://github.com/junegogo0830/cannon_deeplearning)의 코드와 연구 기록을 포트폴리오용으로 선별·정리한 것이다. 출처와 반영한 버전은 [SOURCE.md](SOURCE.md)에 기록했다.

## 데이터와 접근

| 항목 | 내용 |
|---|---|
| 이미지 | JPG 47,267장, 1,024×768 RGB |
| 대상 | 13개 기종, 분석 대상 제품 3,214개 |
| 불량 자료 | NG 이미지 12장, 9개 제품, 3개 기종 |
| 라벨 | 별도 정답표 없이 NG 폴더=FAIL, 루트 사진=PASS로 가정 |
| 실행 조건 | CPU, 정상 이미지 중심 학습 |

NG 폴더가 곧 해당 사진의 가시적 결함을 뜻하는지는 확정되지 않았다. 정상 표본이 적은 기종과 촬영 자세 차이도 평가의 제약이다. 원본 이미지는 포함하지 않는다.

## 분석 흐름

이미지 품질·폴더 구조 확인 → 기종×스텝 분리 → 정상 기반 이상탐지 비교 → 미검출 원인·정렬 점검 → ROI 존재 검사·문자 검사 → PASS/FAIL/REVIEW

- 사전학습 MobileNetV3-Small을 고정 특징 추출기로 사용하고 patch-kNN·PaDiM·AutoEncoder를 비교했다. CNN 백본을 새로 학습한 프로젝트는 아니다.
- ORB 정렬 실패 시 ECC를 재시도하고, 원본 정렬 후 리사이즈하도록 처리 순서를 수정했다.
- 범용 이상점수로 놓친 누락·문자 오류를 ROI-PaDiM과 문자 분할·NCC로 별도 검사했다.
- 정렬·문자 분할이 불확실하면 REVIEW로 구분했다. 형상·위치 전용 검사(C)는 해결되지 않았다.

## 결과: 제출 보고서와 후속 통합을 구분

| 단계 | 확인된 결과 | 해석 |
|---|---|---|
| 제출 보고서의 범용 비교 | NG **1/11 → 2/11**, 개선 후 정상 FPR **1.60%** | 같은 주요 2개 기종·28개 스텝의 제한된 평가. 제품 기준 검출은 1/8 |
| 제출 보고서의 문자 검사 | 정상 holdout 문자 분할 **20/59 → 50/59** | 분할 성공 50장에서 오탐 0건, 나머지 9장은 REVIEW |
| 현재 팀 저장소의 후속 통합 | 같은 NG 12장 기준 **2/12 → 6/12** 검출 기록 | 이미 개별 검증한 전용 모듈을 자동 연결한 결과. 새로운 독립 불량 평가가 아님 |

후속 통합 수치는 현재 팀 README·보고서의 기록이다. 원본 데이터·모델·통합 평가 결과 JSON이 공개 저장소에 없으므로 이번 정리 과정에서 재계산하지 않았다. 11장과 12장의 분모를 혼합하지 않으며, 50%를 일반적인 공정 불량 검출률로 제시하지 않는다.

## 최종 판단

단일 범용 모델의 점수만으로 전체 검사를 대체하기보다, 기종·스텝별 검사 목적에 맞는 모듈을 연결하고 불확실한 사진은 사람이 재검토하는 방향을 채택했다. 촬영 조건 표준화와 새로운 불량 자료 확보가 우선이다.

## 재현 범위

코드 구문과 파일 구성을 점검했다. 원본 공정 이미지와 학습 아티팩트가 없어 전체 모델 학습·NG 재평가는 실행하지 않았다. 최초 사전학습 가중치 다운로드에는 인터넷 연결이 필요하다. 요구 패키지에는 CNN 경로에서 실제 사용하는 `torchvision`을 추가했다.

원본 이미지·제품별 상세 목록·모델 가중치·학번·서명 문서는 제외했다. 제공된 Word 보고서는 품질검사와 모델 개선, 후속 모듈 실험을 담은 제출 시점의 기록이다. 팀 저장소의 후속 통합 구현과 구분해 읽는다.
