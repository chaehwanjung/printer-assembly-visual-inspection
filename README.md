# 프린터 조립 공정 이미지 이상탐지 및 PASS/FAIL 판정

2026학년도 2학기 「딥러닝의 기초 및 응용」 프로젝트 · 7조

핸디형 카메라로 촬영한 프린터 조립 공정 사진에서 부품 누락과 문자 오류를 검사한 팀 프로젝트다. 불량 이미지가 12장뿐이어서 정상 이미지 기반 이상탐지를 비교하고 검사 목적별 모듈을 구성했다.

모델 개선 전 이미지 품질 확인과 최종 분석 결과 정리·해석을 보조했다. 모델·검사 모듈 코드는 팀 결과물이며 [출처와 역할](SOURCE.md)에 구분했다.

## 데이터와 결과

13개 기종·3,214개 제품의 JPG 47,267장을 사용했다. 별도 정답표가 없어 NG 폴더를 FAIL, 제품 루트 사진을 PASS로 가정했다.

| 단계 | 결과 |
|---|---|
| 제출 보고서의 범용 모델 비교 | NG 1/11 → 2/11, 개선 후 정상 FPR 1.60% |
| 문자 분할 개선 | 정상 holdout 20/59 → 50/59 성공, 성공 50장에서 오탐 0건·나머지 9장 REVIEW |
| 후속 모듈 통합 | 같은 NG 12장에서 범용 2/12 → 통합 6/12 검출 기록 |

11장과 12장은 평가 범위가 다르다. 후속 6/12는 이미 확인한 전용 모듈을 자동 연결한 결과로 신규 불량의 독립 평가가 아니다. 원본·모델이 없어 이번 정리 과정에서 다시 계산하지 않았다.

## 분석 과정

이미지 품질 확인 → 기종·스텝 분리 → 이상탐지 비교 → 미검출·정렬 점검 → 존재·문자 검사 → PASS/FAIL/REVIEW

사전학습 MobileNetV3-Small의 고정 특징으로 patch-kNN·PaDiM·AutoEncoder를 비교했다. ORB 실패 시 ECC 정렬을 시도하고, 누락은 ROI-PaDiM, 문자 오류는 분할·NCC로 검사했다. [가로형 워크플로우](https://lucid.app/lucidchart/c9b91030-6f79-4601-9cd7-1720de01f08a/edit)

범용 모델 하나로 모든 검사를 처리하기보다 부품 존재·문자 등 검사 목적에 맞춰 모듈을 연결했다. 정렬이나 문자 분할이 불확실한 사진은 REVIEW로 넘긴다. 형상·위치 전용 검사는 미완성이다.

## 실행과 한계

`requirements.txt`로 패키지를 설치하고 실행 안내에 따라 데이터·모델을 준비한다. 원본 공정 이미지, 제품별 상세 목록과 모델 가중치는 포함하지 않았다. 최초 사전학습 가중치 다운로드에는 인터넷이 필요하다.

불량 표본이 극소수이고 폴더 기반 라벨의 의미가 미확정이다. 같은 제품의 반복 사진과 사후 개선 과정도 평가에 영향을 준다. 일부 통합 정상 평가에서는 모듈 자체 학습 자료와의 완전 분리가 확인되지 않았다. 전체 기종의 일반화 성능과 현장 효과는 추가 평가가 필요하다.

팀 구성원: 최병준, 정채환, 전승민, 최진.
