1. 데이터 탐색(EDA) 및 문제 정의

1.1 데이터 구성과 분석 대상

분석 대상은 핸디형 카메라로 촬영한 프린터 부품 조립 공정 이미지이다. 제품별 폴더에 기종 및 촬영 단계(step)가 기록되어 있으며, 일부 제품에는 NG 폴더가 별도로 존재한다. 데이터 전수 조사에서 기종별 스텝 수, 파일 오류, 반복 이미지, NG 분포를 우선 확인하였다.

1.2 라벨의 정의와 분석 범위

별도의 정답 CSV가 없어 NG 폴더의 이미지를 FAIL, 루트 폴더의 이미지를 PASS로 간주하였다. 이는 분석을 위한 작업 라벨이며, NG가 해당 이미지의 가시적 부품 결함인지, 다른 검사 기록이나 제품 수준의 이상을 포함하는지는 확정할 수 없다. 폴더 구조가 중첩된 2개 제품은 분석에서 제외하였다.

실제 NG가 존재하는 기종은 3029C003AA(7장), 3029C009AA(4장), 3029C004AA(1장)이다. 비교적 많은 정상 제품을 확보한 앞의 두 기종에 대해 28개 스텝을 중심으로 모델을 비교하였다. 해당 범위의 NG는 11장으로, 서로 다른 제품 8개에서 발생한다.

1.3 검사 일람표와 스텝 대응

검사 일람표에는 부품 또는 검사 항목이 제시되어 있으나 모든 기종에서 체크포인트 번호가 파일명 step_N과 일치하는 것은 확인되지 않았다. 일부 기종에서 참고사진과 실제 이미지의 대응을 검증한 뒤 해당 범위 내에서만 부품별 검사를 수행하였다. step_0은 바코드가 촬영된 단계로 별도 취급하였다.

EDA 결과, 정상 제품 수는 기종에 따라 2개부터 1,222개까지 크게 달랐고, NG는 3개 기종에 집중되어 있었다. 따라서 단일 지도학습 분류기보다 정상 이미지의 분포를 이용하는 이상탐지를 초기 모델로 선정하였다.

1.4 NG 보유 스텝의 분포

주요 2개 기종에서 NG가 존재하는 기종·스텝 조합은 총 7개이다. 003AA는 step2·6·7·9·14의 5개 스텝에 NG 7장, 009AA는 step3·8의 2개 스텝에 NG 4장이 있다. 이는 서로 다른 스텝 번호가 7개라는 뜻이 아니라 기종을 포함한 조합이 7개라는 뜻이다. 004AA의 1장은 정상 표본이 적어 주요 정량 비교에서 별도 취급하였다.

정상 제품이 많은 기종에서도 부품별 촬영 배경과 자세가 달라, 같은 기종의 서로 다른 step을 하나의 정상 분포로 합치는 것은 적절하지 않았다. 이에 학습과 임계값 산정의 기본 단위를 기종×스텝으로 설정하였다. 반면 특징 추출기와 이상점수 계산 코드는 재사용하도록 분리해 기종마다 별도 CNN을 학습하는 연산을 줄였다.

2. 초기 이상탐지 모델 개발

2.1 특징 추출과 이상점수

정상 데이터만으로 학습하기 위해 patch-kNN, PaDiM, AutoEncoder를 직접 구현하였다. CPU 연산량을 고려하여 사전학습 MobileNetV3-Small에서 패치 특징을 추출하고, 특징의 거리 계산·통계 추정·임계값 판정은 별도 코드로 구성하였다. CNN 가중치는 재학습하지 않았으며, 비교 실험에서 ResNet18의 일부 계층도 사용하였다.

patch-kNN은 입력 패치와 정상 메모리 뱅크 사이의 최근접 거리를 이상점수로 사용한다. 정렬 오차에 상대적으로 유연하지만 서로 다른 위치의 배경 패치가 정상의 대체 후보로 선택될 수 있다. PaDiM은 같은 격자 위치의 정상 패치 임베딩 평균과 공분산을 추정해 마할라노비스 거리로 평가하므로 정확한 이미지 정렬이 중요하다[3,4]. AutoEncoder는 입력 화소의 재구성 오차를 기준으로 비교하였다.

2.3 초기 결과의 해석

이상점수의 순위가 유리하더라도 실제 운영 임계값에서 불량을 검출하지 못할 수 있으므로 AUROC, 정상 FPR, NG 검출 건수를 함께 보고하였다. 또한 스텝별로 NG가 존재하지 않으면 정상 분포에 대한 평가만 가능하며, 해당 스텝의 불량 검출력을 직접 검증했다고 해석하지 않았다.

기본 접근은 전역 이미지의 이상 정도를 계산하는 방식이었다. 그러나 실제 검사 대상은 전체 이미지의 차이가 아니라 특정 부품의 존재, 문자 내용 또는 장착 상태일 수 있으므로, 이후 실험에서는 놓친 NG 이미지를 개별적으로 진단하였다.

2.4 스텝별 학습과 추론 절차

각 스텝에서 정상 학습 이미지를 추출한 뒤 특징 맵을 패치 단위로 구성하였다. patch-kNN은 학습된 정상 패치 집합과의 최소 거리, PaDiM은 위치별 평균·공분산에 대한 편차를 계산했다. 여러 패치의 점수는 상위값 또는 최대값으로 집계하고 정상 validation 점수의 99백분위수를 판정 임계값으로 사용하였다. 학습에 사용하지 않은 정상 holdout을 통해 FPR을 별도로 계산하였다.

CPU 환경에서는 모델별 입력 이미지를 반복 처리하는 비용이 커, MobileNetV3-Small의 동결된 특징을 공유하고 가우시안 통계량 또는 정상 패치 뱅크를 저장하는 구성을 선택하였다. PaDiM에서는 패치별 분산을 안정화하기 위한 정규화 항을 공분산에 추가하였다. 이러한 설계는 GPU 없이도 반복 실험이 가능하도록 했지만, 위치별 통계의 정확도는 정렬 품질에 민감하다.

3. 평가 설계와 영상 정렬 개선

3.1 검증 표본과 제품 단위 분할

초기에는 일부 스텝의 정상 검증 이미지가 8~12장에 불과하였다. 이 상태에서 99백분위수 임계값은 거의 최댓값 하나에 의해 결정되어 정상 FPR이 11~19%로 불안정했다. 이에 검증용 정상 이미지를 먼저 확보하고 남은 이미지 중에서 학습용 표본을 고르는 reserve_val_then_train 방식을 도입하였다. 정상 표본이 충분한 스텝에서 검증 이미지를 최소 150장 확보한 후 FPR은 약 0.8~2.7% 범위로 안정되었다.

또한 동일 제품이 train·validation에 동시에 포함되거나 NG 제품의 다른 스텝 사진이 정상 학습 풀에 혼입되지 않도록 제품 키 기준의 분할 검사(assert_product_disjoint)를 추가하였다. 이 조치로 이미지 개수를 기준으로 무작위 분리할 때 발생할 수 있는 제품 단위 누수를 차단하였다.

3.2 ORB와 ECC를 결합한 정렬

대표 결함인 3029C003AA step2의 Canon 각인 누락을 분석하자, 각인 부재로 특징점이 감소해 ORB 정렬이 실패하는 문제가 확인되었다. 결함 때문에 특징점이 줄어든 경우 정렬 자체가 포기되면 위치별 특징을 비교하는 PaDiM에서 필요한 패치 대응이 깨진다. 따라서 ORB 특징점 기반 RANSAC 정렬을 우선 적용하고, 특징점·매칭 수가 부족할 때에만 명암 기반 ECC 정렬을 시도하도록 수정하였다[5–7].

ORB 정렬의 신뢰도 조건은 inlier 15개 이상, 비율 0.25 이상으로 설정하였다. 이동 허용 범위는 원본 1,024×768 해상도 기준 x축 ±200px, y축 ±150px, 회전 ±20°이다. ECC로 추정한 변환도 같은 물리적 범위에 들어와야 사용한다.

3.3 전처리 순서와 정렬 실패 정책

기존 코드에서는 이미지를 축소한 후 원본 해상도 기준 픽셀 허용값을 그대로 적용하는 오류가 있었다. 이를 원본 해상도 정렬 → ROI 추출 또는 리사이즈 → 특징 추출 순서로 변경하였다. 아울러 정렬 실패 사진을 모두 제외하면 최대 55%가 평가 대상에서 사라지는 문제가 있어 범용 비교에서는 정렬 전 이미지를 보존하는 정책을 사용하였다. 실제 운영에서 정렬 불확실성이 큰 경우에는 REVIEW로 분리하도록 설계를 확장하였다.

3.4 개선된 범용 기준선

ORB→ECC 정렬과 PaDiM을 적용한 동일 28개 스텝 평가에서 정상 FPR은 평균 1.60%, NG 검출은 2/11이었다. 다만 검출된 두 장은 동일 제품의 같은 스텝 촬영본이므로 제품 단위로는 1/8이었다. 이 결과는 정렬 개선의 효과를 제한적으로 보여주지만, 범용 단일 모델의 검출력이 운영 목적에 충분하지 않음을 확인시켰다.

3.5 모델 평가 시 유지한 기준

검증과 평가는 같은 제품을 공유하지 않는 것을 원칙으로 하였고, NG가 존재하는 제품은 정상 학습 후보에서 제외하였다. NG가 없는 스텝은 실제 결함 검출 건수 대신 정상 holdout FPR과 합성 결함 반응을 보조 지표로 기록하였다. 합성 결함은 실제 공정 NG와 다르기 때문에 합성 이미지의 검출을 실제 불량 검출률로 대체하지 않았다.

제품별 검사 결과는 스텝 단위 결과와 별도로 해석하였다. 동일 제품에서 연속 촬영된 NG가 여러 장이면 이미지별 검출 건수가 증가해도 검출된 불량 제품의 수는 변하지 않을 수 있다. 이후 정량 비교에는 이미지 기준과 제품 기준의 분모를 모두 명시하였다.

4.2 실패 원인 분석

정상 메모리 뱅크의 크기를 늘리거나 검색 가능한 패치 위치를 넓히면, 결함 패치가 정상 이미지의 다른 위치 또는 다른 제품의 유사한 패치와 매칭되는 현상이 발생할 수 있다. 실제 실험에서도 정상 학습 표본을 늘리거나 최근접 검색 범위를 확대했을 때 검출이 감소했다. 다만 이 현상을 모든 미검출의 단일 원인으로 단정하지는 않았다.

전역 참고사진 템플릿 매칭에서는 매칭 점수의 제품 간 편차가 작아도 실제 위치가 대상 부품이 아닌 배경으로 이동했다. 따라서 유사도 점수만으로 ROI 위치를 확정할 수 없으며, 정상 기준 사진에서의 위치 검증이 우선되어야 한다는 결론을 얻었다.

4.3 접근 방식 변경

위 실험에서 특징 추출기나 분포 추정기를 바꾸는 것만으로 새로운 NG 사례의 검출이 증가하지 않았다. 따라서 이후에는 이미지 전체의 이상점수를 하나로 계산하는 방식에서 벗어나 검사 대상과 결함 유형에 맞춰 ROI, 문자 정보, 장착 구조를 분리해 검사하도록 설계를 변경하였다.

4.4 최종적으로 제외한 방법

전역 NCC 매칭에서 검색 스케일과 회전 범위를 확장하였지만, 가장 높은 유사도 점수의 위치가 일람표에 나타난 실제 부품과 일치하지 않았다. 따라서 점수만으로 결정된 자동 ROI를 학습 데이터로 사용하지 않았다. CutPaste형 합성 결함에서는 단색 패치의 경계가 주요 판별 특징이 될 수 있어 실제 부품 누락이나 문자 오부착과 같은 의미적 결함으로 일반화되지 않았다.

반복 실험의 핵심은 모델 구조의 대소 비교가 아니라 검출 실패가 발생하는 위치를 식별하는 것이었다. 범용 특징이 사용되는 전체 이미지보다 실질적인 검사조건이 있는 국소 부품 영역으로 비교 범위를 제한하고, 문자·위치 오류처럼 의미가 다른 검사 조건을 분리하는 설계가 필요하였다.

5.2 A 모듈: 존재 여부 확인

Canon 각인 및 명판 누락처럼 검사 대상이 국소적으로 사라지는 경우 전체 이미지의 패치 점수에는 변화가 희석될 수 있다. 해당 스텝의 정상 참고사진에서 검사항목의 위치를 정한 뒤 원본 종횡비와 해상도를 최대한 보존하여 ROI-PaDiM을 적용하였다. 이는 동일한 물리적 부위를 비교하는 범위를 좁혀 배경 및 조명 차이의 영향을 줄이기 위한 구성이다.

첫 ROI 실험에서는 이미 확인된 NG와 정상 사진 사이의 차이 영상으로 검사 영역을 고른 문제가 있었다. 이 방식은 정답을 보고 검사 위치를 선택하는 편향이 있으므로, 후속 실험에서는 NG를 사용하지 않고 정상 참고사진만으로 ROI를 다시 지정하였다. 새 위치에서도 Canon 각인 누락(3029C003AA step2)과 명판 전체 누락(3029C009AA step3)의 검출 신호가 유지되었다.

5.3 ROI 적용 시 제한

촬영 자세가 다른 기준 이미지의 ROI 좌표를 변환 없이 그대로 쓰면 다른 부위를 검사할 수 있다. 따라서 정렬 결과에서 ROI가 실제 대상 부품을 포함하는지 정상 표본 여러 장으로 교차 확인하였다. 본 연구에서 A 모듈의 효과는 확인된 누락 사례에 한정되며, 모든 기종에서 동일 검출률을 보장하지 않는다.

5.4 정상 이미지 기반 ROI 지정 절차

기준 정상 이미지와 일람표 참고사진에서 우선 부품 위치를 확인하고, 다른 정상 제품의 촬영 사진에서 동일 부위가 ROI에 포함되는지 검사하였다. ROI의 점수 비교 이전에 위치가 맞는지를 검증함으로써 배경이나 제품 외곽의 유사한 질감이 선택되는 전역 매칭 문제를 피하고자 하였다. 정상 참조 좌표를 다른 사진으로 옮길 때에는 정렬 변환과 ROI 좌표계가 일치하는지 함께 확인하였다.

검사 부위가 정확히 위치하더라도 정상 제품마다 조명과 촬영 거리 차이가 존재하므로 임계값은 별도의 정상 검증 사진에서 산정하였다. 미검증 스텝에 대해서는 일람표상 검사 목적이 비슷하다는 이유만으로 NG 검출 성능이 같을 것으로 가정하지 않았으며, 검증된 검사 항목과 실제 결함 사례가 없는 항목을 구분해 기록하였다.



6. 문자 내용 검사 모듈 개발

6.1 외관 이상점수로 구분하지 못한 사례

3029C009AA step3의 명판에는 정상 기대 문자열 2206N 대신 2006N이 부착된 NG 사례가 있었다. 명판의 색상과 질감은 정상과 유사하므로 ROI-PaDiM의 점수는 15.7로 임계값 43.9를 넘지 못했다. 이에 문자 내용을 직접 확인하는 B 모듈을 추가하였다.

6.2 문자 분할 방식의 수정

초기에는 명판 ROI를 예상 글자 수에 맞게 다섯 등분하고 각 구간의 NCC를 계산했지만, 촬영각과 정렬 오차에 따라 글자 경계가 달라져 정상 사진에서도 점수가 불안정했다. 다음 단계에서는 Otsu 이진화와 연결성분 분석으로 문자 외곽을 분할하고 왼쪽부터 정렬하여 정상 템플릿과 비교하였다[8,9]. 이 방법은 오부착 NG의 틀린 글자 위치를 드러냈으나, 정상 사진에서 분할 실패와 인디케이터 박스의 오인식이 발생했다.

정상 데이터만으로 임계값을 선택해 검증하자 문자 분할 성공률이 낮아 내용 오류를 안정적으로 판정하지 못했다. 영상 확인 결과 회색 인디케이터 박스가 추가 문자로 검출되거나 그림자 때문에 문자 윤곽이 붙는 문제가 확인되었다. 이에 인디케이터 박스를 위치·밝기로 제외하고, 지역 적응형 이진화와 약한 모폴로지 연산을 적용하였다.

6.4 실제 판정 흐름과 한계

명판이 존재하지 않는 경우 A 모듈의 부품 존재 검사로 판정한다. 존재 검사를 통과한 사진에 대해서만 문자 분할과 위치별 NCC 비교를 수행하고, 기대 문자열의 글자 수 및 문자 간격 조건을 함께 평가한다. 분할이 실패한 사진을 즉시 FAIL로 처리하면 정상 촬영 조건의 변화가 오탐으로 이어질 수 있으므로 REVIEW로 처리한다.

수정 후 정상 holdout 59장 중 50장에서 문자 분할이 성공하였다. 이 50장에서는 고정된 임계값으로 오탐이 발생하지 않았으나, 9장은 자동 판정 대상에서 빠졌다. 따라서 0건의 오탐을 전체 검사 완성도로 해석하지 않고 분할 성공률 및 REVIEW율을 함께 보고하였다. validation 150장과 holdout 59장을 합한 209장은 모두 독립 holdout이 아니라는 점도 구분하였다.



7. 형상·위치 검사와 라벨 진단

7.1 C 모듈: 형상 및 위치 검사

부품 형상·장착 상태 검사를 위해 ROI-PaDiM 외에 엣지 밀도와 상대 위치에 기반한 경량 기하학적 특징을 시험하였다. 그러나 압판스토퍼(step14)와 코마(step6)의 NG에서는 유의미한 검출 성과를 얻지 못하였다. 두 사례의 원인을 동일하게 취급하지 않고 ROI 추출의 안정성과 해당 부위 점수의 분별력을 나누어 조사하였다.

Step14는 촬영 자세 차이에 따라 ROI 안에 들어오는 구조물이 달라졌다. 정상 사진 40장 중 약 25~40%에서 핵심 구조가 ROI 밖으로 이동했으며, 기준 사진을 바꾸면 같은 NG에 대해 추정된 회전각이 크게 달라졌다. 이 경우 먼저 일관된 물리적 부위를 찾는 기준점 추정이 필요하다. Step6은 정상 사진 12장 중 10장에서 ROI가 실제 코마 부위를 포함했지만, NG와 정상의 이상점수 차이가 충분하지 않았다. 위치 불안정과 특징 분별력 부족이 서로 다른 문제임을 확인하였다.

7.2 D 모듈: 장면 불일치와 판정 보류

일부 NG는 대응 root 사진과 검사 장면 자체가 달랐다. 이 경우 원래 검사항목의 부품 누락과 촬영 위치 오류를 같은 종류의 FAIL로 취급하기 어렵다. 따라서 비교가 불가능한 이미지에는 무리하게 PASS/FAIL을 부여하지 않고 REVIEW로 분리하는 설계를 채택하였다. REVIEW는 불량 검출에 성공한 건수로 집계하지 않으며, 향후 자동화율과 검토 부담을 별도로 평가해야 한다.

7.3 NG 촬영 시각 분석

NG 이미지가 짧은 시간에 몰려 있다는 관찰로 동일 제품 재검사 묶음 가능성을 검토하였다. 그러나 3029C003AA에서는 NG가 대응 root 이미지보다 약 2~5초 먼저 기록되는 패턴이 나타났으며, 일반 제품의 스텝 간 촬영 간격(약 2.3~3.7초)과 유사하였다. 3029C009AA에서는 0~114초로 간격이 불규칙해 동일한 촬영 규칙을 적용할 수 없었다.

이 분석은 특정 NG가 해당 스텝에서 먼저 촬영된 기록일 수 있음을 시사하지만, 그 이미지가 곧 해당 부품의 시각적 결함을 뜻한다고 증명하지는 않는다. 이에 NG 폴더의 기존 라벨을 유지하고, 확인 가능한 외관 결함·장면 불일치·원인 불명 사례를 구분하여 결과를 보고하였다.

기존 구현에는 범용 PaDiM의 제품별 스텝 순회 추론과 A·B 개별 추론 스크립트가 존재한다. 다만 문서 작성 시점에는 A·B가 전체 제품 순회 명령에 자동 연결된 상태가 아니므로, 통합 시스템의 성능으로 간주하지 않는다. 모든 구현·검증은 CPU에서 수행하였으며 추론 과정에서 신규 학습을 요구하지 않도록 기존 저장 아티팩트를 활용하였다.

8.2 전체 기종 적용 결과와 통계적 한계

범용 PaDiM의 공식 평가 결과는 주요 2개 기종의 NG 2/11, 제품 단위 1/8, 평균 정상 FPR 1.60%이다. 13개 기종의 총 195개 기종·스텝 조합 중, 비교적 정상 표본이 충분한 6개 기종(86개 스텝)에서는 정상 FPR이 0.85~2.07%였다. 정상 표본이 적은 6개 기종(94개 스텝)은 검증 표본과 평가 표본이 겹쳐 독립 FPR 추정이 어렵고, 정상 제품이 2개뿐인 1개 기종(15개 스텝)은 일반 PaDiM 평가를 수행할 수 없었다.

극소표본 기종에서 out-of-fold 임계값을 사용해 순환 평가를 완화했으나, 표본이 2~25개이면 FPR 값은 대략 1/n의 거친 단위로 제한된다. 따라서 개선된 수치를 곧 일반화 성능 향상으로 해석하지 않았다. 주요 11장 자체도 표본이 작고 동일 제품의 반복 이미지가 있어 정확한 검출률 추정에는 제약이 있다[10].
