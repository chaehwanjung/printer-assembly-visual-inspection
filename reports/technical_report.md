# 공정 이미지 이상탐지 기술보고서

## 문제 정의

프린터 부품 조립 공정에서 촬영한 이미지의 PASS/FAIL 판정을 다룬다. 실제 NG 12장이라는 극소 표본과 CPU 연산 제약 때문에 정상 분포에서 벗어나는 이미지를 찾는 방법을 우선 비교했다. 최종적으로는 검사 목적에 맞춘 존재·문자 검사와 REVIEW를 포함한 구조를 검토했다.

개인 기여는 모델 개선 전 사진 품질 확인과 최종 분석 결과 보조이며, 이하 구현·실험은 팀 성과다.

## 데이터와 품질 확인

전체 파일 47,270개 중 JPG는 47,267개다. 분석 대상은 13개 기종·3,214개 제품이며 잘못 중첩된 2개 제품을 제외했다. 모든 이미지는 1,024×768 RGB이고 보고서상 디코딩 실패와 SHA-256 완전 중복은 0건이다. NG는 3개 기종의 9개 제품에서 12장 확인됐다.

별도 정답 CSV가 없어 NG 폴더를 FAIL, 제품 루트 이미지를 PASS로 가정했다. 파일명 스텝과 사진 내용이 다른 사례가 있으며, NG가 실제 가시적 부품 결함을 뜻하는지는 미확정이다. 일람표 체크포인트와 step 번호의 대응도 모든 기종에서 검증되지 않았다.

## 범용 모델과 정렬 개선

사전학습 MobileNetV3-Small을 동결해 패치 특징을 추출했다. patch-kNN은 정상 패치와의 최근접 거리, PaDiM은 격자 위치별 평균·공분산과 마할라노비스 거리, AutoEncoder는 재구성 오차를 사용한다. ResNet18 특징도 비교했다.

주요 2개 기종·28개 스텝에서 초기 patch-kNN의 평균 AUROC는 0.756, PaDiM은 0.724, AutoEncoder는 0.389였다. 실제 NG 검출은 각각 1/11, 1/11, 0/11이었다. AUROC와 운영 임계값에서의 검출을 함께 봐야 하므로 AUROC만으로 모델을 최종 평가하지 않았다.

놓친 NG를 확인한 뒤 ORB 특징점이 부족할 때 ECC로 재정렬하도록 보완했다. 원본 해상도 정렬 후 리사이즈하도록 좌표계 오류도 수정했다. 정렬 실패 이미지를 일괄 제외하면 최대 55%가 빠지는 문제 때문에 범용 비교에서는 원본을 보존하고, 운영 설계에서는 불확실한 입력을 REVIEW로 처리했다.

개선된 PaDiM은 같은 주요 평가에서 NG 2/11, 정상 평균 FPR 1.60%였다. 두 검출 이미지는 같은 제품·스텝의 촬영본이라 제품 기준으로는 1/8이다. 정상 FPR의 평균과 이미지별 불량 검출은 서로 다른 집계량이다.

## 검사 목적별 모듈

| 검사 | 방법 | 확인 범위 |
|---|---|---|
| 존재(A) | 정상 참조 ROI의 PaDiM | 각인·명판 누락의 알려진 사례 |
| 문자 내용(B) | 문자 분할·위치별 NCC·문자 수와 간격 | 명판 오부착·문자 누락의 알려진 사례 |
| 형상·위치(C) | 기하학·엣지·기준점 탐색 | 검출 성과 미확보, 전용 판정기 미완성 |
| 범용(D, 후속 코드 명칭) | 정렬+PaDiM | 전용 모듈이 없는 스텝의 참고 이상탐지 |

제출 문서는 D를 검사 불가·REVIEW 설계로 설명하지만, 후속 코드에서 D는 범용 PaDiM 어댑터 명칭이다. 포트폴리오에서는 문자 코드보다 실제 검사 기능으로 설명한다.

초기 ROI가 이미 확인한 NG와의 차이로 지정된 편향을 발견하고 정상 참고사진만으로 다시 지정했다. 알려진 NG를 보고 방법을 개선한 사후 사례 분석이라는 한계는 남는다.

문자 분할 개선 후 정상 validation은 66/150→128/150, 정상 holdout은 20/59→50/59에서 분할에 성공했다. 고정 임계값으로 분할 성공 50장에서 오탐 0건이며 9장은 REVIEW다. 150장의 validation과 59장의 holdout을 합친 209장을 모두 독립 시험으로 표시하지 않는다.

## 제출 문서와 후속 통합의 차이

제공된 Word 보고서에는 A·B가 전체 제품 순회 명령에 자동 연결되지 않았다고 기록돼 있다. 현재 팀 저장소에는 registry→router→decision과 통합 추론·평가 스크립트가 추가돼 있다.

후속 보고서상 동일 NG 12장에 범용 D만 적용하면 2/12, 검증된 전용 모듈을 자동 라우팅하면 6/12다. 늘어난 4장은 기존 A·B에서 이미 확인한 사례로, 자동 연결의 결과이며 새로운 독립 NG 평가 성과가 아니다. 형상·위치 C는 여전히 미구현이다.

일부 통합 정상 FPR 평가가 D의 holdout을 재사용했고 A·B 자체 학습 목록과의 완전 분리가 확인되지 않았다. 따라서 통합의 정상 오탐 0%를 독립 일반화 성능으로 제시하지 않는다. 원본·모델·통합 결과 JSON이 공개 저장소에 없어 이 정리 과정에서 해당 수치를 재산출하지 않았다.

## 최종 방향과 한계

기종·스텝별로 검사항목과 임계값을 관리하고 존재·문자 등 의미가 다른 검사를 분리한다. 불확실한 정렬·문자 분할·장면 불일치는 REVIEW로 전달한다. 실제 운영 전에는 촬영 자세 표준화, 라벨 확인, 신규 불량 자료 확보, 제품 단위 독립 평가가 필요하다.

NG가 극소량이고 동일 제품의 반복 사진이 포함돼 있다. 정상 제품 2개 수준의 기종에서는 오탐률 추정도 불안정하다. 현장 불량 유출 감소, 전 기종 검출률과 처리시간·자동화율은 입증하지 않았다.
